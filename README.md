# midgar-owl
OWLBEAR Plugins for the GM of Midgar and his friends.

La fiche suit les dégâts dans une piste de 40 cases, réparties en dix groupes de quatre. Le malus du groupe atteint s’applique aux jets de compétence. L’entrée des dégâts tient compte de la protection d’armure de la localisation touchée ; les groupes Mortelle déclenchent chacun un test de survie à leur première case.
